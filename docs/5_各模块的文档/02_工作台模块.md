## 1. 模块概述

### 1.1 模块定位

工作台模块是用户登录后的**首屏聚合视图**，按权限展示个人的待办任务、阻断级问题、高风险需求、待确认归因、最近任务和数据源异常状态。数据应标明更新时间；无权限内容不得展示名称、摘要或数量。

### 1.2 解决的业务问题

- 多个分析任务分散在不同模块，用户需要一个统一的入口快速了解当前工作状态
- 阻断级问题和待确认结论需要及时触达相关责任人
- 数据源异常可能影响分析任务，需要主动提示

### 1.3 在整体架构中的位置

工作台位于应用服务层，是一个**只读聚合服务**，不产生自己的业务数据。它从各业务模块（评估、检查、归因、项目）拉取数据并按用户权限聚合展示。

```
用户登录 → 工作台首页
              │
   ┌──────────┼──────────┐
   ▼          ▼          ▼
评估模块    检查模块    归因模块    项目/数据源模块
(tasks)   (issues)   (attrib)    (data_sources)
```

## 5. 数据聚合逻辑

### 5.1 WorkspaceService 核心方法

```python
class WorkspaceService:
    def __init__(self, db: AsyncSession, tenant_id: UUID, current_user: User):
        self.db = db
        self.tenant_id = tenant_id
        self.user = current_user

    async def get_dashboard(
        self,
        project_ids: list[UUID] | None = None,
        limit: int = 5,
    ) -> WorkspaceResponse:
        """聚合工作台六个区域的数据。

        数据来源：
        1. pending_reviews — tasks 表（status='pending_review'）
        2. blockers — check_issues 表（level='blocker', status NOT IN ('closed','waived')）
        3. risk_flagged — assessment_tasks 表（has_risk_flag=true, status='pending_review'）
        4. pending_attributions — tasks 表（task_type='attribution', status='pending_review'）
        5. recent_tasks — tasks 表（created_by=user, ORDER BY updated_at DESC）
        6. data_source_alerts — data_sources 表（last_sync_status='failure' OR status='error'）
        """
```

### 5.2 查询优化

- 六个区域的查询**并行执行**（`asyncio.gather`），减少总响应时间
- 每区域限制 `limit` 条，避免大结果集
- 使用数据库索引：
  - `tasks`: `idx_tasks_tenant_type_status` — 按类型和状态查待办
  - `check_issues`: `idx_issues_status` — 按状态查阻断问题
  - `data_sources`: `idx_sources_tenant` — 按租户查异常数据源
- 增删索引不需要

### 5.3 权限过滤

- 普通成员（`project_member`）：仅返回其加入的项目数据
- 租户管理员（`tenant_admin`）：可查看租户下所有项目数据
- 所有查询强制带 `tenant_id` 过滤

## 6. 权限与安全

### 6.1 权限控制

| 角色 | 可见范围 |
| --- | --- |
| `tenant_admin` | 租户下所有项目的待办/问题/风险/归因 |
| `project_admin` | 所管理项目的全部数据 |
| `project_member` | 所加入项目的全部数据 |
| `viewer` | 所加入项目的只读数据 |

### 6.2 数据安全

- 无权限的项目不在查询结果中出现
- 每条返回数据包含 `project_name` 用于前端分组，但仅在用户有该项目权限时返回
- 无独立审计需求（工作台为只读查询）

---

## 7. 异常处理与边界条件

| 场景 | 处理方式 |
| --- | --- |
| 用户无任何项目 | 返回空工作台，各区域均为空数组，summary 全为 0 |
| 某区域查询超时 | 该区域返回空数组并记录 WARNING 日志，不影响其他区域 |
| 大量数据（如 100+ 个阻断问题） | 通过 `limit` 参数控制返回量，前端可点击"查看全部"跳转对应列表页 |
| 数据源状态拉取失败 | 降级：显示最后已知状态 + `last_sync_at` |
