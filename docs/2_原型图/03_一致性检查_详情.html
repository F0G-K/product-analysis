字段

手机号必填属性不一致

置信度: 高
PRD §3.1: 用户下单时手机号为必填字段
接口 §POST /order: phone 字段定义为 optional
影响：可能导致订单创建时缺少联系方式，无法发送通知
建议修正：将接口 phone 改为 required 推荐角色：研发负责人
状态： 待确认
阻断 #2
权限

退款操作权限定义冲突

置信度: 高
PRD §5.2: 退款操作仅管理员可执行
接口 §POST /refund: 权限定义为 role: member（普通成员可调用）
此问题为越权风险，涉及资金安全
建议修正：接口层增加角色校验，限制为 admin 推荐角色：研发负责人 + 产品负责人
状态： 待确认
