# 原型图

基于 [PRD V1.2](../1_prd/产品管理智能助手平台_PRD.md) 设计的产品管理智能助手平台原型图。

## 页面清单

| 编号 | 文件 | 页面名称 | 说明 |
|------|------|----------|------|
| 00 | `00_登录.html` | 用户登录 | 邮箱密码登录、SSO 单点登录入口、MFA 动态码输入、错误/锁定状态展示 |
| 00 | `00_忘记密码.html` | 忘记密码 | 邮箱验证、密码强度检测、多步骤流程（输入邮箱→邮件已发送→设置新密码→完成）、链接过期提示 |
| 01 | `01_工作台.html` | 工作台 | 统计卡片、待办列表、风险概览、最近任务、快速操作入口 |
| 02 | `02_需求价值评估_列表.html` | 需求价值评估（列表） | 筛选、评估任务表格、状态/优先级分布、分页 |
| 03 | `02_需求价值评估_详情.html` | 需求价值评估（详情） | 总分环形图、五维评分、证据链、敏感性分析、排名、审计 |
| 04 | `03_一致性检查_列表.html` | 一致性检查（列表） | 统计行、检查任务表格、基线编号、问题等级分布 |
| 05 | `03_一致性检查_详情.html` | 一致性检查（详情） | 基线信息、交付物关联、问题按维度分组、对照引用、阻断警告 |
| 06 | `04_问题归因_列表.html` | 问题归因（列表） | 筛选、归因任务表格、五类归因标签、置信度 |
| 07 | `04_问题归因_详情.html` | 问题归因（详情） | 异常摘要、时间线、证据链、候选归因、处置建议、人工确认 |
| 08 | `05_报表.html` | 报表 | KPI 指标卡、需求/质量/归因趋势图表 |
| 09 | `06_项目管理.html` | 项目与数据源管理 | 项目列表、数据源连接状态、同步记录 |

## 设计说明

- 使用 HTML + Tailwind CSS (CDN) + Font Awesome 实现
- 统一的左侧导航菜单，支持所有页面间跳转
- 暗色侧边栏 + 浅色内容区配色方案
- 入口页面：`index.html`
- 所有页面可直接在浏览器中打开使用
