# Markdown Output Skill

生成 Markdown 文档时，必须遵循以下规范：
- 每生成一个md文档,必须在文档第一行加“本文档约xxx字,阅读本文档越xxx分钟”。
- 禁止写"为保障平台内容安全，营造绿色网络环境"这种话,禁止写口水话.
- 使用标准 Markdown 语法，不使用 HTML 标签。
- 文档仅允许一个一级标题（`#`），标题层级不得跳级。
- 段落、标题、列表、代码块之间保留一个空行。
- 列表统一使用 `-`（无序）或 `1.`（有序）。
- 所有代码块必须标注语言。
- 命令、文件名、变量名使用行内代码（`` `...` ``）包裹。
- 表格使用标准 Markdown 表格格式。
- 链接使用 `[文本](URL)` 格式，不直接输出裸链接。
- 内容简洁、准确、结构清晰，避免重复和无关说明。
- 输出仅包含最终 Markdown 内容，不添加解释、前言、结尾或其他额外文字。
