### 2.2 模块职责边界

| 层 | 职责 | 不允许 |
| --- | --- | --- |
| `api/` | 路由注册、参数校验、认证注入、响应序列化 | 包含业务逻辑；直接操作数据库 |
| `schemas/` | 请求/响应的数据结构定义与校验 | 包含业务方法 |
| `models/` | ORM 映射、表结构定义、基础关系 | 包含业务逻辑；包含 API 级别的校验 |
| `services/` | 业务逻辑编排、事务管理、权限校验 | 直接操作 HTTP 请求/响应对象 |
| `workflows/` | LangGraph 图定义、节点实现、状态管理 | 直接操作 HTTP 层；包含 CRUD 业务逻辑 |
| `rag/` | 文档解析、向量化、检索、重排序 | 包含分析任务特定逻辑 |
| `rules/` | 规则 DSL 解析、确定性冲突判定 | 调用外部 API |
| `connectors/` | 外部系统数据拉取、格式转换 | 包含分析逻辑；持久化业务数据 |

### 3.4 异步优先

- 所有 I/O 操作（数据库、HTTP、Redis）使用 `async/await`
- Service 和 Repository 方法默认为 `async def`
- 仅在 CPU 密集型任务（文档解析、规则执行）中使用线程池

```python
# 正确
async def get_task(db: AsyncSession, task_id: UUID) -> Task:
    stmt = select(Task).where(Task.id == task_id)
    result = await db.execute(stmt)
    return result.scalar_one_or_none()

# CPU 密集型操作使用线程池
import asyncio

async def parse_document(file_path: str) -> list[Document]:
    loop = asyncio.get_running_loop()
    return await loop.run_in_executor(None, _parse_document_sync, file_path)
```

### 3.5 依赖注入

FastAPI 依赖注入链：`请求 → 认证 → 租户上下文 → DB Session → 路由处理`。

```python
# api/deps.py

async def get_current_user(
    token: str = Depends(oauth2_scheme),
    db: AsyncSession = Depends(get_db),
) -> User:
    """从 JWT Token 解析当前用户。401 时抛出未认证异常。"""
    payload = decode_access_token(token)
    user = await user_service.get_by_id(db, UUID(payload["sub"]))
    if not user:
        raise HTTPException(status_code=401, detail="User not found")
    return user


async def get_current_tenant(
    current_user: User = Depends(get_current_user),
) -> UUID:
    """从当前用户提取租户 ID。"""
    return current_user.tenant_id


async def get_tenant_db(
    tenant_id: UUID = Depends(get_current_tenant),
    db: AsyncSession = Depends(get_db),
) -> AsyncSession:
    """在数据库会话中设置租户上下文（RLS）。"""
    await db.execute(
        text("SET app.current_tenant_id = :tid"), {"tid": str(tenant_id)}
    )
    return db
```

### 3.6 Repository 模式

每个模型对应一个 Repository 类，封装数据访问逻辑：

```python
# models/repositories/task_repo.py

from typing import Optional
from uuid import UUID
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from models.task import Task

class TaskRepository:
    def __init__(self, db: AsyncSession, tenant_id: UUID):
        self.db = db
        self.tenant_id = tenant_id

    async def get_by_id(self, task_id: UUID) -> Optional[Task]:
        stmt = (
            select(Task)
            .where(Task.id == task_id)
            .where(Task.tenant_id == self.tenant_id)
        )
        result = await self.db.execute(stmt)
        return result.scalar_one_or_none()

    async def list_by_project(
        self,

        page: int = 1,

    ) -> tuple[list[Task], int]:
```

### 4.3 统一响应格式

```python
# schemas/common.py
from typing import Generic, TypeVar
from pydantic import BaseModel

T = TypeVar("T")

class ApiResponse(BaseModel, Generic[T]):
    code: int = 0
    message: str = "success"
    data: T
    request_id: str

class PaginatedData(BaseModel, Generic[T]):
    items: list[T]
    total: int
    page: int
    page_size: int
```

不直接在路由中手动构造响应，使用 FastAPI 的 `response_model` 自动序列化。

### 4.4 参数校验

- 路径参数、查询参数、请求体均通过 Pydantic 自动校验
- 业务校验在 Service 层执行，抛出 `BusinessError` 由全局异常处理器捕获
- 不依赖 Pydantic 处理复杂业务规则

```python
# 全局异常处理器
from fastapi import Request
```

### 6.2 查询规范

- 所有查询必须包含 `tenant_id` 过滤
- 列表查询默认分页：`page`（1-based）、`page_size`（默认 20，最大 100）
- 排序通过 `sort_by` 白名单控制，防止 SQL 注入

```python
ALLOWED_SORT_FIELDS = {"created_at", "updated_at", "status", "current_total_score"}

async def list_requirements(
    db: AsyncSession,
    tenant_id: UUID,
    project_id: UUID,
    *,
    status: Optional[str] = None,
    priority: Optional[str] = None,
    search: Optional[str] = None,
    page: int = 1,
    page_size: int = 20,
    sort_by: str = "created_at",
    sort_order: str = "desc",
) -> tuple[list[Requirement], int]:
    if sort_by not in ALLOWED_SORT_FIELDS:
        raise BusinessError(ErrorCode.INVALID_SORT_FIELD)

    stmt = select(Requirement).where(
        Requirement.tenant_id == tenant_id,
        Requirement.project_id == project_id,
        Requirement.deleted_at.is_(None),
    )
    # 动态过滤
    if status:
        stmt = stmt.where(Requirement.status == status)
    if search:
        stmt = stmt.where(Requirement.name.ilike(f"%{search}%"))

    # 排序
    col = getattr(Requirement, sort_by)
    stmt = stmt.order_by(col.desc() if sort_order == "desc" else col.asc())

    # 分页
    count_stmt = select(func.count()).select_from(stmt.subquery())
    total = (await db.execute(count_stmt)).scalar()

    stmt = stmt.offset((page - 1) * page_size).limit(page_size)
    items = (await db.execute(stmt)).scalars().all()

    return list(items), total
```

```python
# workflows/base.py

def build_base_workflow() -> StateGraph:
    """构建通用分析工作流骨架。

    子类通过以下方式定制：
    - 替换特定节点（如 llm_analyze 替换为评分/比对/归因）
    - 添加模块特有节点（如敏感性分析、复检）
    - 自定义路由条件
    """
    workflow = StateGraph(AnalysisState)

    # 注册节点
    workflow.add_node("validate_input", validate_input_node)
    workflow.add_node("lock_snapshot", lock_snapshot_node)
    workflow.add_node("retrieve_docs", retrieve_docs_node)
    workflow.add_node("run_rules", run_rules_node)
    workflow.add_node("llm_analyze", llm_analyze_node)
    workflow.add_node("link_evidence", link_evidence_node)
    workflow.add_node("calc_confidence", calc_confidence_node)
    workflow.add_node("human_review", human_review_node)
    workflow.add_node("finalize", finalize_node)
    workflow.add_node("handle_error", handle_error_node)

    # 注册边
    workflow.set_entry_point("validate_input")
    workflow.add_conditional_edges("validate_input", route_after_validate, {
        "valid": "lock_snapshot",
        "invalid": "handle_error",
    })
    workflow.add_edge("lock_snapshot", "retrieve_docs")
    workflow.add_conditional_edges("retrieve_docs", route_after_retrieval, {
        "has_rule_items": "run_rules",
        "llm_only": "llm_analyze",
    })
    workflow.add_edge("run_rules", "llm_analyze")
    workflow.add_edge("llm_analyze", "link_evidence")
    workflow.add_edge("link_evidence", "calc_confidence")
    workflow.add_edge("calc_confidence", "human_review")
    workflow.add_conditional_edges("human_review", route_after_review, {
        "confirmed": "finalize",
        "revised": "llm_analyze",
        "rejected": "handle_error",
    })
    workflow.add_edge("finalize", END)
    workflow.add_edge("handle_error", END)

    return workflow
```

### 8.3 混合检索

```python
# rag/retriever.py

class HybridRetriever:
    """Dense（向量相似度）+ Sparse（BM25 关键词）混合检索。"""

    def __init__(self, alpha: float = 0.7):
        """
        Args:
            alpha: 语义检索权重，1-alpha 为关键词检索权重。
                   默认 0.7（偏重语义）。
        """
        self.alpha = alpha
        self.vector_store = get_vector_store()
        self.bm25 = get_bm25_index()

    async def search(
        self,
        query: str,
        top_k: int = 20,
        filters: dict | None = None,
    ) -> list[dict]:
        """执行混合检索并返回合并后的 Top-K 结果。

        Args:
            query: 检索查询文本。
            top_k: 返回结果数。
            filters: 元数据过滤条件，至少包含 tenant_id。
        """
        # 向量检索
        dense_results = await self.vector_store.similarity_search_with_score(
            query, k=top_k * 2, filter=filters
        )

        # BM25 关键词检索
        sparse_results = self.bm25.search(query, k=top_k * 2)

        # 融合排序（Reciprocal Rank Fusion）
        merged = self._rrf_fusion(dense_results, sparse_results, alpha=self.alpha)

        return merged[:top_k]
```

```python
class SensitiveMasker:

    送大模型前的最后一道防线。在分块后、嵌入前执行。

    PATTERNS = {

    def mask(self, text: str) -> str:

            text = pattern.sub(replacement, text)
        return text
```

```python
规则 DSL 语法（EBNF）：

rule         := "MATCH" source "WITH" target condition+ "RETURN" result
source       := path ("WHERE" filter)?
target       := path ("WHERE" filter)?
path         := identifier ("." identifier | "[*]" | "[" index "]")*
condition    := "WHERE" comparison ("AND" comparison)*
comparison   := path operator value
operator     := "=" | "!=" | ">" | "<" | "IN" | "CONTAINS"
result       := "CONFLICT" | "MISSING"
"""
```

```python
# rules/engine.py

class RuleEngine:
    """规则引擎：确定性冲突优先判定。"""

    def __init__(self):
        self.rules: list[dict] = []   # 从数据库加载的启用规则

    async def load_rules(self, db: AsyncSession, project_id: UUID) -> None:
        """加载项目启用规则（含通用规则）。"""
        # 项目规则优先级高于通用规则
        self.rules = await self._load_active_rules(db, project_id)

    def execute(self, documents: dict[str, ParsedDocument]) -> list[dict]:
        """对所有文档执行所有适用规则。

        Returns:
            [{rule_id, dimension, title, level, confidence: "high",
              involved_docs: [{doc_id, citation, excerpt}],
              comparison: str}]
        """
        results = []
        for rule in self.rules:
            # DSL 解析 + 执行
            finding = self._execute_single(rule, documents)
            if finding:
                finding["confidence"] = "high"  # 规则判定结果置信度高于 LLM
                results.append(finding)
        return results
```

```python
# connectors/base.py
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from datetime import datetime
from typing import AsyncIterator

@dataclass
class SyncItem:
    """单个同步条目。"""
    external_id: str
    name: str
    content_type: str       # MIME 类型
    content: bytes           # 原始内容（脱敏前）
    metadata: dict = field(default_factory=dict)
    updated_at: datetime | None = None

@dataclass
class SyncResult:
    """同步结果汇总。"""
    items_added: int = 0
    items_updated: int = 0
    items_deleted: int = 0
    items_failed: int = 0
    errors: list[dict] = field(default_factory=list)

class BaseConnector(ABC):
    """外部系统连接器基类。

    子类必须实现：
    - test_connection(): 连通性测试
    - fetch_items(): 增量拉取变更
    - to_parsed_document(): 格式转换为 ParsedDocument
    """

    def __init__(self, config: dict):
        self.config = config
        self.name: str = config.get("name", self.__class__.__name__)

    @abstractmethod
    async def test_connection(self) -> dict:
        """测试连通性。

        Returns:
            {"status": "connected"/"error", "latency_ms": int, "message": str}
        """
        ...

    @abstractmethod
    async def fetch_items(
        self,
        since: datetime | None = None,
        scope: dict | None = None,
    ) -> AsyncIterator[SyncItem]:
        """增量拉取变更条目。

        Args:
            since: 上次同步时间，首次全量同步时为 None。
            scope: 可选的同步范围限定。
        """
        ...

    async def sync(
        self,
        db: AsyncSession,
        since: datetime | None = None,
    ) -> SyncResult:
        """标准同步流程：拉取 → 脱敏 → 解析 → 分块 → 嵌入 → 入库。"""
        result = SyncResult()
        async for item in self.fetch_items(since):
            try:
                # 脱敏
                masked_content = masker.mask(item.content.decode())
                # 解析
                doc = await self.parser.parse(masked_content)
                # 分块 + 嵌入
                chunks = splitter.split_documents([doc])
                await vector_store.add_documents(chunks)
                # 记录
                result.items_added += 1
            except Exception as e:
                result.items_failed += 1
                result.errors.append({"external_id": item.external_id, "error": str(e)})
        return result
```

### 16.3 健康检查

```python
# main.py
@app.get("/health")
async def health_check():
    """Kubernetes liveness probe。"""
    return {"status": "ok"}

@app.get("/health/ready")
async def readiness_check(db: AsyncSession = Depends(get_db)):
    """Kubernetes readiness probe（含数据库连通性）。"""
    try:
        await db.execute(text("SELECT 1"))
        return {"status": "ready", "database": "connected"}
    except Exception:
        return JSONResponse(
            status_code=503,
            content={"status": "not_ready", "database": "disconnected"},
        )
```

### 16.4 启动顺序

```
1. PostgreSQL   → 数据库初始化 + 迁移
2. Redis        → 缓存 + Celery Broker
3. ChromaDB     → 向量存储
4. MinIO / S3   → 对象存储
5. Celery Worker → 异步任务处理（--concurrency=4）
6. FastAPI      → API 服务（--workers=4）
7. Nginx        → 反向代理 + SSL + 静态资源
```
