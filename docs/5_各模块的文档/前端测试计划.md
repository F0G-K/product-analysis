## 1. 概述

### 1.1 范围

本文档覆盖产品管理智能助手平台前端 8 个模块的测试计划，包含组件测试、集成测试和 E2E 测试用例。

### 1.2 优先级定义

| 标记 | 含义 |
| --- | --- |
| 🔴 P0 | 核心路径，阻塞上线。PRD 验收标准直接覆盖项 |
| 🟠 P1 | 主要功能，应在本迭代完成 |
| 🟡 P2 | 边界场景和辅助功能 |
| 🟢 P3 | 体验优化，可延后 |

### 1.3 测试类型标记

| 标记 | 类型 | 工具 |
| --- | --- | --- |
| UT | 单元测试 | Vitest |
| IT | 集成测试 | Vitest + RTL |
| E2E | 端到端 | Playwright |
